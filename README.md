# Нейрон — тренажёр для мозга

PWA-приложение для iPhone: память, внимание, логика, эрудиция. 15 игр, адаптивная сложность, прогресс двух игроков, работа без интернета.

- **Хостинг:** GitHub Pages (автодеплой при каждом пуше в `main`).
- **Данные:** сначала на телефоне (localStorage), затем синхронизация с Google Таблицей через Apps Script.
- **Без зависимостей:** чистый HTML/CSS/JS, никаких CDN — всё кэшируется для офлайна.

## Игры

| Категория | Игры |
|---|---|
| Память | Матрица, Цепочка, Пары |
| Внимание | Шульте, Струп, Оттенок, Реакция |
| Логика и счёт | Быстрый счёт, Больше-меньше, Числовой ряд |
| Эрудиция и слова | Викторина (1 200+ вопросов, 7 тем), Флаги и столицы, Анаграммы, Правописание, Ударения |

## 1. Публикация на GitHub Pages

1. Создайте репозиторий `brain-trainer` и запушьте проект в ветку `main`.
2. `Settings → Pages → Build and deployment → Source: GitHub Actions`.
3. Дождитесь workflow «Deploy to GitHub Pages». Адрес: `https://<логин>.github.io/brain-trainer/`.

## 2. Синхронизация между телефонами (Google Таблица)

1. Создайте Google Таблицу «Нейрон — результаты».
2. `Расширения → Apps Script`, вставьте код из [apps-script/Code.gs](apps-script/Code.gs), сохраните.
3. Выберите функцию `setup` → «Выполнить» → разрешите доступ.
4. `Начать развертывание → Новое развертывание → Веб-приложение`: выполнять от имени **«Я»**, доступ **«Все»**.
5. Скопируйте ссылку `…/exec` в [js/config.js](js/config.js) → `API_URL` и запушьте.

Без `API_URL` приложение полностью работает, но данные хранятся только на одном телефоне. Адрес сервера можно также указать в самом приложении: «Настройки → Адрес сервера».

## 3. Установка на iPhone

Safari → открыть ссылку → «Поделиться» → «На экран „Домой“». Приложение откроется на весь экран, будет работать без интернета и обновляться само при запуске с сетью.

## Офлайн

- Все файлы кэширует service worker ([sw.js](sw.js)): сначала сеть (чтобы получать обновления), без сети — кэш.
- Результаты пишутся на телефон и уходят в таблицу, когда появляется сеть (очередь видна в «Настройках»).
- Первый запуск и получение обновлений — только при наличии интернета.

## Структура

```
index.html            оболочка PWA
manifest.json, sw.js  установка на экран «Домой» и офлайн
css/app.css           стили (светлая/тёмная тема)
js/config.js          настройки: API_URL, профили по умолчанию
js/core.js            утилиты, звук, вибрация, игровые часы с паузой
js/store.js           результаты, рейтинги, серии (localStorage)
js/sync.js            синхронизация с Apps Script
js/ui.js, js/app.js   интерфейс и экраны
js/games/*.js         игры по категориям
js/data/*.js          вопросы, справочники, слова
apps-script/Code.gs   сервер для Google Таблицы
tools/make-icons.js   генерация иконок: node tools/make-icons.js
```

## Как добавить вопросы

- Ручные вопросы — [js/data/quiz.js](js/data/quiz.js) и [js/data/quiz2.js](js/data/quiz2.js): `[тема, вопрос, правильный, неверный, неверный, неверный]`.
- Справочники (страны, книги, картины, даты…) — [js/data/sets.js](js/data/sets.js), [js/data/sets2.js](js/data/sets2.js): вопросы и варианты генерируются автоматически. Новые строки добавляйте **в конец** массива, чтобы не сбить учёт уже показанных вопросов.

## Локальный запуск

```bash
node tools/serve.js
```
