# Нейрон — тренажёр для мозга

PWA-приложение для iPhone: память, внимание, логика, эрудиция и головоломки. 26 игр, выбор уровня, понятный рейтинг, прогресс нескольких игроков, работа без интернета.

- **Хостинг:** GitHub Pages (автодеплой при каждом пуше в `main`).
- **Данные:** сначала на телефоне (localStorage), затем синхронизация с Google Таблицей через Apps Script.
- **Без зависимостей:** чистый HTML/CSS/JS, никаких CDN — всё кэшируется для офлайна.

## Игры

| Категория | Игры |
|---|---|
| Память | Матрица, Цепочка, Пары, Числа, Слова, N-назад, Что изменилось, Лица и имена |
| Внимание | Шульте, Струп, Оттенок, Реакция |
| Логика и счёт | Быстрый счёт, Больше-меньше, Числовой ряд |
| Эрудиция и слова | Викторина (1 400+ вопросов, 10 тем, разбор ответов), Верю — не верю, Хронология, Кто лишний, Флаги и столицы, Анаграммы, Правописание, Ударения |
| Головоломки | Судоку (4 сложности, заметки, кандидаты, подсказки, сохранение партии), Кроссворд, Слова из букв |

## Как считается индекс

- У каждой игры есть **эталон** — результат хорошо натренированного игрока (виден в карточке игры).
- **Рейтинг игры** (0–100) = среднее 3 лучших результатов из последних 10 игр ÷ эталон × 100.
- **Индекс категории** — среднее рейтингов её игр; **индекс мозга** — среднее по категориям.
- Ранги: 0 Новичок · 20 Любитель · 40 Опытный · 60 Эксперт · 80 Мастер · 95 Гений.

Уровень в играх подстраивается сам («Авто»), но его можно выбрать вручную в карточке игры.

## 1. Публикация на GitHub Pages

1. Репозиторий должен быть **публичным** (на бесплатном тарифе Pages работает только для публичных).
2. `Settings → Pages → Build and deployment → Source: GitHub Actions`.
3. Каждый пуш в `main` публикует сайт: `https://<логин>.github.io/brain-trainer/`.

## 2. Синхронизация (Google Таблица)

1. Создайте Google Таблицу, `Расширения → Apps Script`, вставьте [apps-script/Code.gs](apps-script/Code.gs).
2. Запустите `setup`, затем `Развертывание → Веб-приложение` (от имени «Я», доступ «Все»).
3. Ссылку `…/exec` пропишите в [js/config.js](js/config.js) → `API_URL`.

Игроков можно добавлять прямо в приложении («Настройки → Добавить игрока») — они синхронизируются между телефонами.

## 3. Установка на iPhone

Safari → «Поделиться» → «На экран „Домой“». Работает на весь экран и без интернета; обновляется при запуске с сетью.

## Структура

```
index.html, manifest.json, sw.js   оболочка PWA и офлайн
css/                              стили (app, ui2, games2, puzzles)
js/config.js                      API_URL и профили по умолчанию
js/core.js, store.js, sync.js     ядро, данные и рейтинги, синхронизация
js/ui.js, app.js                  интерфейс и экраны
js/games/*.js                     игры по категориям
js/data/*.js                      вопросы, справочники, словарь, определения
apps-script/Code.gs               сервер для Google Таблицы
tools/                            иконки и локальный сервер
```

## Как добавить контент

- Вопросы: [js/data/quiz.js](js/data/quiz.js), [quiz2.js](js/data/quiz2.js), [quiz3.js](js/data/quiz3.js) — `[тема, вопрос, правильный, неверный, неверный, неверный]`.
- Справочники (страны, книги, картины, даты…): [js/data/sets.js](js/data/sets.js), [sets2.js](js/data/sets2.js) — вопросы и определения кроссворда генерируются автоматически. Новые строки добавляйте **в конец** массивов.
- Определения кроссворда: [js/data/clues.js](js/data/clues.js); словарь: [js/data/dict.js](js/data/dict.js).

## Локальный запуск

```bash
node tools/serve.js
```
